# Devin — An Interactive Journey

An interactive 3D portfolio inspired by locations in Japan.

## First prototype
- Four destination worlds: Kyoto (About), Tokyo (Projects), Hakone (Experience), Kamakura (Contact)
- Procedurally generated scenery, stations, train travel, and playable avatar
- WASD / arrow-key movement, Shift to sprint, E to board when near a station
- Mobile-friendly touch movement and WebGL fallback

## Deploy on Vercel
Import https://github.com/DevinEldrian/Portofolio into Vercel. For Vite use npm run build and output dist.

## Development
Run npm install, npm run dev; then npm test and npm run build.

Japan locations are stylized artistic interpretations, not exact geospatial reproductions. Portfolio facts and project details should be reviewed before publication.
